# Mood Echo (무드에코)

## "목소리만으로 마음의 감기를 알아채는 AI"

---

## 이 프로젝트가 뭔가요?

우울증에 걸리면 목소리가 달라집니다. 톤이 낮아지고, 말이 느려지고, 에너지가 줄어듭니다. **무드에코**는 이런 목소리의 변화를 AI가 분석하여 우울증 가능성을 조기에 알려주는 서비스입니다.

병원에 가지 않아도, 설문지를 작성하지 않아도, 짧은 대화 한 번이면 됩니다. 마이크에 대고 이야기하면 AI가 음성 속 패턴을 읽어 "주의가 필요한 상태인지"를 판단합니다.

---

## 왜 만들었나요?

산업 현장에서 일하는 근로자들의 정신건강 문제가 심각합니다. 우울증은 집중력 저하와 판단력 감소를 유발해 산업재해로 이어질 수 있지만, 기존 방식에는 한계가 있습니다.

| 기존 방식 | 문제점 |
|-----------|--------|
| PHQ-9 설문지 | 솔직하게 답하지 않으면 정확도가 떨어짐 |
| EAP(근로자 지원 프로그램) | 인식 부족으로 이용률이 매우 낮음 |
| 정신과 방문 | 사회적 편견과 시간 부담으로 꺼리는 경우가 많음 |

무드에코는 이 문제를 해결하기 위해 **음성 분석**이라는 비침습적(몸에 직접 접촉하지 않는) 방법을 선택했습니다. 목소리를 녹음하는 것만으로 진행되기 때문에 사생활 부담이 적고, 주기적인 모니터링도 가능합니다.

---

## 어떻게 동작하나요?

전체 과정을 4단계로 나눌 수 있습니다.

### 1단계: 음성 데이터 준비

실제 임상 인터뷰 음성 데이터를 사용했습니다. 미국 서던캘리포니아 대학에서 공개한 **DAIC-WOZ** 데이터셋으로, 275명의 참가자가 AI 인터뷰어(Ellie)와 대화한 녹음입니다. 각 참가자에게는 전문가가 평가한 우울 점수(PHQ-8)가 부여되어 있습니다.

이 녹음에서 인터뷰어의 목소리를 제거하고, 참가자의 목소리만 분리한 뒤, 배경 소음도 제거하여 깨끗한 음성 데이터 **5,067개 샘플**을 만들었습니다.

### 2단계: 음성에서 특징 뽑아내기

사람이 귀로 듣는 "어두운 목소리"를 컴퓨터가 이해할 수 있는 숫자로 바꿔야 합니다. 이 과정을 **피처(Feature) 추출**이라고 합니다.

여기서 핵심 기술이 **Wav2Vec 2.0**입니다. 이 AI는 수만 시간의 음성을 미리 들으며 "목소리의 패턴"을 스스로 학습한 모델입니다. 마치 음악을 수만 곡 들은 사람이 첫 몇 초만 듣고도 장르를 구별하는 것처럼, Wav2Vec 2.0은 짧은 음성만 들어도 목소리의 특징을 768개의 숫자로 요약할 수 있습니다.

이 외에도 다음과 같은 전통적인 음향 특징을 함께 추출했습니다.

| 특징 | 쉽게 말하면 |
|------|-------------|
| Mel-spectrogram | 소리를 시간-주파수 그래프로 변환한 "음성 지문" |
| MFCC | 사람의 청각 구조를 모방하여 추출한 음성 요약 정보 |
| Zero-Crossing Rate | 소리 파형이 얼마나 자주 진동하는지 (목소리 떨림 관련) |
| RMS Energy | 소리의 크기, 즉 에너지 (우울 시 에너지가 감소하는 경향) |

### 3단계: AI 모델 학습

추출한 숫자 데이터를 바탕으로 "이 목소리의 주인이 우울한가, 아닌가"를 판별하는 AI 모델을 학습시켰습니다.

4가지 머신러닝 알고리즘을 비교 실험한 결과, **XGBoost**가 가장 높은 정확도를 보여 최종 모델로 선정했습니다.

| 알고리즘 | 쉽게 말하면 | 정확도 |
|----------|-------------|--------|
| Logistic Regression | 가장 기본적인 분류 방법 | 69.39% |
| SVM | 데이터 사이에 최적의 경계선을 긋는 방법 | 69.36% |
| Gradient Boosting | 약한 예측기를 순차적으로 보완하며 강해지는 방법 | 69.69% |
| **XGBoost** | Gradient Boosting의 개선 버전, 더 빠르고 정확 | **69.82%** |

> 위 정확도는 5-Fold Cross Validation(데이터를 5등분하여 번갈아 검증한 평균) 기준입니다.

### 4단계: 성능 평가

학습에 사용하지 않은 별도의 테스트 데이터(194개 샘플)로 최종 성능을 측정했습니다.

| 평가 지표 | 결과 | 의미 |
|-----------|------|------|
| **정확도(Accuracy)** | 81.44% | 전체 예측 중 맞힌 비율 |
| **정밀도(Precision)** | 100% | "우울하다"고 예측한 경우 실제로 모두 맞음 |
| **재현율(Recall)** | 52.63% | 실제 우울한 사람 중 절반 정도를 탐지 |
| **F1 Score** | 0.69 | 정밀도와 재현율의 균형 점수 |

**해석:** 모델이 "우울하다"고 판단하면 그 판단은 매우 정확하지만, 실제 우울한 사람 중 절반 정도를 놓치고 있습니다. 향후 이 부분을 개선하면 실용적인 스크리닝 도구로 발전할 수 있습니다.

---

## 어떤 실험을 했나요?

Wav2Vec 2.0에는 여러 버전이 있습니다. "어떤 언어의, 얼마만큼의 음성을 미리 학습했느냐"에 따라 성능이 달라지기 때문에, 5가지 버전을 비교 실험했습니다.

| 모델 | 특징 | 비유 |
|------|------|------|
| Base | 영어 음성으로 기본 학습 | 영어 초급자 |
| Base-960h | 영어 960시간 분량 추가 학습 | 영어 중급자 |
| Large-960h | 더 큰 두뇌로 960시간 학습 | 영어 고급자 |
| XLSR-Korean | 한국어 포함 다국어 학습 | 다국어 능통자 (한국어 특화) |
| XLSR-53-English | 53개 언어 학습 후 영어 특화 | 다국어 능통자 (영어 특화) |

결과적으로 **Base-960h**(영어 중급자 수준)이 가장 안정적인 성능을 보였습니다. 모델이 무조건 크다고 좋은 것은 아니며, 데이터 양과 모델 복잡도의 균형이 중요하다는 교훈을 얻었습니다.

## 개선할 점은?

| 한계 | 개선 방향 |
|------|-----------|
| 영어 데이터로 학습함 | 한국어 우울증 음성 데이터 확보 필요 |
| 우울한 사람을 절반만 탐지 | 데이터 불균형 보정, 임계값 조정으로 개선 가능 |
| 피처 추출과 분류가 분리됨 | End-to-End 딥러닝으로 통합 시 성능 향상 기대 |

## 향후 서비스 확장 계획

```
1단계  제조업/건설업 현장 시범 도입
         근로자가 출근 시 간단히 음성을 녹음하면 AI가 주기적으로 모니터링

2단계  일반 소비자 시장 확장
         스마트폰 앱 형태로 누구나 자가 체크 가능

3단계  AI 상담 연계
         위험 감지 시 전문 상담 서비스와 자동 연결
```
